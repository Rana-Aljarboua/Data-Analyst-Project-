# Data Analyst Project

A practical data analytics project completed as part of the **IBM Data Analyst Professional Certificate**, covering the end-to-end data analysis process from data collection and preparation to exploratory analysis, visualization, dashboard development, and presentation of findings.

---

## Project Overview

This project demonstrates practical skills in:

* Data Collection
* Data Wrangling
* Exploratory Data Analysis (EDA)
* Data Visualization
* Dashboard Development
* Data-Driven Insight Generation

The work includes analyzing technology and developer-related datasets using Python-based analysis and visualization tools, along with an interactive dashboard developed using **IBM Cognos Analytics**.

---

## Project Workflow

**Data Collection → Data Wrangling → Exploratory Data Analysis → Data Visualization → Dashboard → Findings & Presentation**

---

## 1. Data Collection

* Collected data using **APIs**
* Extracted data through **web scraping**
* Worked with external datasets and structured data sources

---

## 2. Data Wrangling

* Identified and removed duplicate records
* Detected and handled missing values
* Applied missing-value imputation techniques
* Normalized data for analysis
* Prepared datasets for exploratory analysis

---

## 3. Exploratory Data Analysis

* Analyzed data distributions
* Identified and handled outliers
* Examined relationships between variables using **correlation analysis**
* Extracted patterns and insights from the data

---

## 4. Data Visualization

Created visualizations to communicate patterns and relationships, including:

* Bar charts
* Line charts
* Pie charts
* Box plots
* Scatter plots
* Bubble plots
* Stacked charts

---

## 5. Dashboard

Developed an interactive **IBM Cognos Analytics dashboard** covering:

* Current technology usage
* Future technology trends
* Developer demographics

The dashboard presents insights across:

* Programming languages
* Databases
* Platforms
* Web frameworks
* Education
* Age
* Geographic distribution

---

## 6. Final Presentation

Presented the key findings and insights from the analysis in a structured final presentation.
